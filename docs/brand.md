# Brand assets

Open Grid uses the **Open Path** mark: one orthogonal route folds through an
implied grid and exits through an open boundary. The uninterrupted path represents
one framework-agnostic core rendered natively across product stacks.

## Primary lockup

The symbol and the words **Open Grid** form the primary lockup. Keep the words in
title case. Product copy and package names continue to use their normal text form;
the symbol does not replace the project name on first mention.

## Colors

| Role | Value | Use |
| --- | --- | --- |
| Grid ink | `#0b241c` | Primary mark, headings, and dark brand surfaces |
| Signal | `#b5ef6f` | Mark on dark surfaces and restrained emphasis |
| Paper | `#f3f7f1` | Light brand surfaces |
| Interface green | `#087a55` | Accessible links and controls on light surfaces |

Signal is an identity color, not body text on light backgrounds. Interface green
is the accessible interactive color in documentation and product examples.

## Clear space and size

Keep clear space around the mark equal to the width of one mark stroke. Do not
display the standalone mark below 16 CSS pixels. Use the compact favicon artwork
at 16 and 32 pixels rather than resampling the full hero composition.

## Variants

- Use the ink mark on white, paper, or other light neutral surfaces.
- Use the signal or white mark on grid ink and other dark neutral surfaces.
- Use one color per mark. The documentation hero may use the signal terminal as
  an intentional motion cue; this is a composition treatment rather than another
  logo variant.
- Preserve the SVG proportions and square terminals.

## Do not

- Put the mark inside a rounded application tile except where an operating system
  requires an icon background.
- Add cell fills, gradients, shadows, or framework logos to the mark.
- Close the path, round its corners, or change the relationship between its turns.
- Use Signal for small text on a light background.
